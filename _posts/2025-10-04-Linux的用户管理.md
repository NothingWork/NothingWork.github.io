## 用户管理

### 创建用户:


```Shell
useradd -m newUser # 创建新用户并自动创建其登录目录
```

### 删除用户:


```Shell
userdel -r oldUser # 删除用户及其关联的登录目录
```

### 设置用户密码:


```Shell
passwd newUser # 为 newUser 设置密码
```

### 用户切换

```Shell
su newUser # 切换用户身份
```

## 用户组管理

### 创建用户组


```Shell
groupadd mygroup # 创建新用户组
```

```Shell
groupadd -g 101 mygroup # 创建时指定用户组的GID
```

### 检查用户组的创建

```Shell
grep 'mygroup' /etc/group  # 检查用户组的创建
```

### 删除用户组

```Shell
groupdel mygroup # 删除用户组
```

### 修改用户组信息

```Shell
groupmod -g 102 mygroup # 修改用户组的GID
```

```Shell
groupmod -n newgroup mygroup # 修改用户组的名称
```
