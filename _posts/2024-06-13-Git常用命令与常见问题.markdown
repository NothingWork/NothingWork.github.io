## 1.git仓库建立连接

每个项目建立一次连接就行

### 1.本地代码初始化

``` sh
git init  git初始化
```

### 2.连接远程仓库

``` sh
git remote add <remote_name> <remote_url>  建立远程仓库连接，name是名字自己起
```

## 2. git代码提交

### 1.本地代码提交

``` sh
git add .  所有代码文件加入本地仓库
git commit -m "提交信息"  提交代码至本地仓库
```

### 2.创建新分支并切换分支

```sh
git branch <branch_name>  新建分支
git checkout <branch_name>  切换分支
git branch  查看当前分支
```

确保你现在的分支是你想要上传代码的分支(绿色带 *)
![alt text](/pictures/003/1.jpg)

### 3.本地代码推送至github

```sh
git push <remote_name>
```

## 3.拉取代码

### 1.克隆仓库

将目标仓库中想要复制的分支复制到本地目录中

```sh
git clone -b <branch_name> <url> <dir>   复制指定仓库指定分支到指定目录
```

### 2.拉取代码

拉取更新代码

```sh
git pull <remote_name> <branch_name>  将远程代码与本地指定分支合并 
```
